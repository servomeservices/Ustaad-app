Servome is a hyperlocal home-services dispatch tool: customers book technicians (electrician, plumber, AC repair) and technicians run their whole job queue -- leads, wallet, live job timer -- from this app. The distinctive thread is "dispatch console": a single characterful grotesque typeface used everywhere (headings and body alike) for a unified, engineered voice; tabular numerals on every balance, timer and count so figures never jitter; hairline dividers instead of heavy borders; one confident blue signal color reserved for primary actions and active/live states, everything else neutral. This is a tool people check between jobs, not a brand showcase -- it should feel like a well-built radio dispatch panel, not a marketing site.
Light and dark mode both supported (technicians work outdoors at all hours; dark mode is not optional).
Pacing register: tight. Dense information (job cards, wallet ledger, status chips) with compact spacing -- this is a working tool, not a landing page.
Global character: flat, slightly warm-neutral surfaces (never stark white/black); one signal blue for CTAs, links and "live/in-progress" states; status meaning carried by a small set of semantic colors (success green for completed/paid, warning amber for awaiting/pending, error red for failed/cancelled) used only on small chips/dots, never as large fills; small radius (crisp, not soft/rounded-corporate); no drop shadows beyond a faint elevation on floating sheets/modals; icons are functional line icons, never decorative illustration.
