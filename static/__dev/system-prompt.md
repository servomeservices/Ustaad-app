Build Servome: a hyperlocal home-services booking platform for Bhopal, India. Customers book technicians (electrician, plumber, AC repair, etc.) via WhatsApp; technicians log in to a dashboard to see and accept leads/tickets, track their wallet and leads balance, go through the accept -> on-the-way -> arrived -> in-progress -> complete flow for a job, and get paid a booking fee per lead. There's also a QR-code shop-dispatcher flow where local shop owners register walk-in customer requests, and an admin view for managing technicians, approvals, and bookings. Rebuild this as a Floot web app (the existing implementation is a React Native/Expo mobile app + Python backend, which Floot can't run directly, so this is a fresh web build of the same product).
